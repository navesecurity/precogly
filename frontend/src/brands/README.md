# Brand profiles

`neutral` is tracked. Any other profile (`nave`, `warwick`) lives in the NS3E repo under `instances/<company>/precogly-brand/` and is copied here by `scripts/ns3e-precogly-brand.sh`.
Select one with `VITE_BRAND=<name>` (default `neutral`). A profile is `brand.ts` (exports `brand`), `brand.css` (token overrides, fonts) and its assets.
